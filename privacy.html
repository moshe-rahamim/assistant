מדיניות פרטיות - Personal Assistant

עודכן לאחרונה: 8 בנובמבר 2026

1. על מה המסמך הזה

"Personal Assistant" היא תוכנת עוזר אישי שמותקנת ורצה במחשב Windows של המשתמש. המסמך הזה עוסק רק באפשרות אחת שלה: החיבור לחשבון Google של המשתמש, שדרכו התוכנה קוראת הקלטות של Google Meet מה-Google Drive שלו, ובמה שקורה למידע שמתקבל דרך החיבור הזה.

2. מי מספק את התוכנה

את התוכנה כתב ומספק משה מנחם דושניצקי, ישראל. יצירת קשר: mmd9404265@gmail.com.

התוכנה רצה במחשב של המשתמש. המפתח לא מפעיל שרת עבור החיבור הזה. המידע שמתקבל מ-Google לא נשלח למפתח ולא נשמר אצלו.

3. איזו גישה מתבקשת מ-Google

החיבור מבקש הרשאה אחת בלבד: https://www.googleapis.com/auth/drive.meet.readonly. זו הרשאת קריאה בלבד, ש-Google מגבילה לקבצי Google Drive שנוצרו או נערכו על ידי Google Meet.

המשתמש מתחבר בדפדפן. לפעמים צריך להתחבר שוב, למשל אם הגישה בוטלה או פגה. התוכנה לא משנה, לא מזיזה, לא משתפת ולא מוחקת שום דבר ב-Google Drive.

4. מה התוכנה עושה עם המידע

רק אם המשתמש הפעיל את האפשרות והתחבר:

  • התוכנה רצה כמשימה ברקע כל עוד המשתמש מחובר ל-Windows. בפעם הראשונה היא מאתרת ב-Drive את תיקיית הקלטות Meet לפי שמה, ומאז, בערך פעם ברבע שעה, קוראת את פרטי הקבצים שבה: שם, תאריכים, גודל, סוג, מזהה ופרטי הבעלים.
  • הקלטת וידאו חדשה מורדת למחשב. כברירת מחדל, הקלטות מלפני היום שבו האפשרות הופעלה לא מורדות.
  • מהעותק שהורד מופק קובץ שמע, ואז העותק המקומי של הווידאו נמחק. ההקלטה המקורית נשארת ב-Drive כמו שהיא.
  • השמע מתומלל במחשב עצמו, במודל זיהוי דיבור שמותקן במחשב. השמע לא נשלח לשירות תמלול חיצוני.
  • כדי לכתוב סיכום, התמלול נשלח, יחד עם שם ההקלטה ושעותיה, ל-Claude של Anthropic, דרך התוכנה Claude Code שמותקנת אצל המשתמש ובחשבון Claude של המשתמש עצמו. הקלטה קצרה משתי דקות מתומללת בלבד ולא נשלחת לסיכום.
  • בשלב הסיכום, Claude עשוי לעיין ביומן, במייל ובחיבורים אחרים שהמשתמש חיבר לחשבון Claude שלו (למשל Zoom), ובקובצי הזיכרון של העוזר במחשב, כדי לזהות את המשתתפים ואת נושא הפגישה. החיבורים האלה נפרדים מהאפליקציה שמתוארת כאן.
  • אם המשתמש חיבר לעוזר קבוצת WhatsApp, נשלחות אליה עד 12 השורות הראשונות של הסיכום, כולל הנושא ושמות המשתתפים. במקרה של תקלה נשלחת לשם גם הודעה שעשויה לכלול את שם קובץ ההקלטה.

5. מה נשמר ואיפה

במחשב של המשתמש נשמרים:

  • בתיקיית הפגישה, בתוך פלט\פגישות שבתיקיית העוזר: קובץ השמע, התמלול, הסיכום, הקובץ name.txt וקובץ מצב שכולל את מזהה הקובץ ב-Drive. שם התיקייה כולל את התאריך, הנושא ושמות המשתתפים.
  • קובץ האינדקס פלט\פגישות\אינדקס.md: שורה לכל פגישה, עם תאריך, נושא ושמות משתתפים.
  • בתיקייה %USERPROFILE%\.assistant\meetings: meet-seen.json (מזהי ההקלטות שכבר טופלו), meet-folder.txt (מזהה תיקיית ההקלטות), meet-error.txt (התקלה האחרונה, אם הייתה) ו-meetings.log (יומן פעולות שכולל שמות של קבצים).
  • אסימוני הגישה ל-Google ופרטי החיבור שמורים בקובץ rclone.conf.dpapi, מוצפנים בהצפנה של Windows (DPAPI) לחשבון Windows של המשתמש. בזמן פעולה מול Drive הם נפתחים לקובץ זמני רגיל, שנמחק בסוף הפעולה, או בפעולה הבאה אם הפעולה נקטעה.

התוכנה לא קובעת תקופת שמירה ולא מוחקת את הקבצים האלה מעצמה, חוץ מ-meet-error.txt, שנמחק כשהבדיקה הבאה מצליחה. הם נשארים במחשב עד שהמשתמש מוחק אותם או מסיר את התוכנה (סעיף 9).

מה שנשלח ל-Claude ולקבוצת WhatsApp נשמר אצל השירותים האלה לפי התנאים שלהם.

Privacy Policy - Personal Assistant

Last updated: 8 November 2026

1. What this covers

"Personal Assistant" is a personal-assistant program installed on and running on the user's own Windows PC. This policy covers only one feature: the connection to the user's Google account through which the program reads the user's Google Meet recordings from Google Drive, and what happens to data received through that connection.

2. Who provides the software

The software is written and provided by Moshe Menachem Dushnitzky, Israel. Contact: mmd9404265@gmail.com.

The program runs on the user's PC. The developer runs no server for this connection. Data received from Google is not sent to the developer and is not stored by him.

3. Access requested from Google

One scope only: https://www.googleapis.com/auth/drive.meet.readonly. It is read-only, and Google limits it to Drive files created or edited by Google Meet.

The user signs in in the browser. Sign-in may need to be repeated, for example if access was revoked or expired. The program does not change, move, share or delete anything in Google Drive.

4. What the program does with the data

Only if the user enabled the feature and signed in:

  • The program runs as a background task while the user is signed in to Windows. The first time, it looks up the Meet recordings folder in Drive by name; from then on, about every 15 minutes, it reads the file details in it: name, dates, size, type, ID and owner details.
  • A new video recording is downloaded to the PC. By default, recordings from before the day the feature was enabled are not downloaded.
  • Audio is extracted from the downloaded copy, and then the local video copy is deleted. The original recording stays in Drive unchanged.
  • The audio is transcribed on the PC itself, with a speech model installed on the PC. The audio is not sent to an external transcription service.
  • To write a summary, the transcript, with the recording's name and times, is sent to Claude (Anthropic) through Claude Code installed on the user's PC, under the user's own Claude account. Recordings shorter than two minutes are only transcribed and are not sent for a summary.
  • During the summary step, Claude may consult the calendar, email and other connectors the user connected to their Claude account (for example Zoom), and the assistant's memory files on the PC, to identify the participants and the topic. Those connections are separate from the app described here.
  • If the user connected a WhatsApp group to the assistant, up to the first 12 lines of the summary are sent there, including the topic and participant names. If an error occurs, a message that may include the recording's file name is also sent there.

5. What is stored and where

Stored on the user's PC:

  • In the meeting folder, inside פלט\פגישות in the assistant folder: the audio file, the transcript, the summary, the file name.txt and a status file that includes the Drive file ID. The folder name includes the date, topic and participant names.
  • The index file פלט\פגישות\אינדקס.md: one line per meeting, with date, topic and participant names.
  • In %USERPROFILE%\.assistant\meetings: meet-seen.json (IDs of recordings already processed), meet-folder.txt (the recordings folder ID), meet-error.txt (the last error, if any) and meetings.log (an activity log that includes file names).
  • The Google access tokens and connection details are kept in rclone.conf.dpapi, encrypted with Windows encryption (DPAPI) for the user's Windows account. During a Drive operation they are opened into a plain temporary file, which is deleted at the end of the operation, or at the next operation if it was interrupted.

The program sets no retention period and does not delete these files on its own, except meet-error.txt, which is deleted when the next check succeeds. They stay on the PC until the user deletes them or removes the program (section 9).

What is sent to Claude and to the WhatsApp group is kept by those services under their own terms.

6. What is not done with the data

  • The developer does not receive the data, sell it, use it for advertising or use it to train models.
  • The program sends nothing to the developer on its own. If the user chooses to contact the developer for support, the user decides what to send.

7. Google API Services User Data Policy and Claude

Personal Assistant's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This is how the program is built: data is passed to Claude only to produce the summary. A condition for enabling the feature is that the user turns off the "Help improve Claude" setting in their Claude account (https://claude.ai/settings/data-privacy-controls). Without the user's confirmation that the setting is off, the program does not download recordings. The developer does not control that setting or how Anthropic handles the data. That handling is governed by Anthropic's terms: https://www.anthropic.com/legal/privacy.

What is sent to the WhatsApp group is governed by WhatsApp's terms: https://www.whatsapp.com/legal/privacy-policy.

8. Revoking access

The user can revoke the app's access to their Google account at any time: https://myaccount.google.com/permissions. After revoking, the program can no longer read from Drive.

9. Removing the program

  • Removing the program ("remove yourself") schedules deletion of the assistant folder and the access token files, within about 3 minutes or at the next Windows sign-in.
  • If the user chooses to keep the memory, the list of processed recordings, the folder ID, the log and the last-error file remain in %USERPROFILE%\.assistant\meetings, and the saved memory remains in %USERPROFILE%\העוזר-זיכרון-שמור.
  • The program does not verify that the deletion completed. The user can check and delete on their own.
  • Removal does not revoke the Google permission. That is done at the link in section 8.

10. Recording participants

Through the Google connection the program only reads recordings Google Meet already saved. The program has a separate option to record meetings on the PC, which does not use Google data. The user is responsible for ensuring the recording and its use are lawful under the law that applies to them.

The last-updated date appears at the top. A new use of Google data will be enabled only after notifying the user and obtaining consent.
